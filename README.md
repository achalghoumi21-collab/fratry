# Fratry, prototype cliquable

Fratry est la cagnotte voyage des 18-25 ans : un groupe finance son départ par une épargne régulière, les aides publiques et des bourses de marque.

Ce dépôt contient le prototype cliquable, une seule page web à ouvrir sur téléphone ou sur ordinateur.

Prototype de démonstration : les paiements, les membres et les marques sont fictifs.
